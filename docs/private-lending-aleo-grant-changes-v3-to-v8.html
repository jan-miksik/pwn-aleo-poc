Elastic Proposal: the default offer type

→ Proposal versus loan. A proposal is an offer and its available funding; each accepted draw creates a separate loan with its own collateral, repayment obligation and maturity. Proposal expiry stops new draws, not existing loans. Cancelling a proposal returns unused funding without cancelling active loans.

… a private record on a counterparty's behalf, so asynchronous acceptance requires one side to commit → counterparty’s behalf, so our asynchronous acceptance flow commits capital in advance. Elastic proposals assume exactly that, and bring three things for free: every offer is → make every offer backed by real capital, offers live in public state so discovery needs no PWN backend, and many draws against one commitment make individual loans harder to link to a lender. → capital and allow discovery from public state without a proprietary backend. Multiple draws reuse one funded offer. The lender’s address stays private in the lending calls, while each loan publicly references the commitment it draws from.
